Learning Blender

For this project, I modeled and rendered 3 everyday objects in Blender: a perfume bottle, a Moka coffee machine, and a peach. Each object pushed me to practice a different skill.

Tree

Ideation

This was the starter tree I created during class. This was my first attempt at modeling, so it's not very good, but it taught me the extrude tool and coloring objects. After class, I adjusted colors and shapes to my liking in order to practice the basic functions.

Approach

I started from a sphere and shaped it to be less perfect and more natural, adding the crease and adjusting the form so it didn't look too symmetrical. Once I was happy with the shape, I focused on texturing the surface, adding color to make it look like real fruit.

Challenges + Learnings

The biggest challenge was making the peach look natural instead of computer-generated. A perfect sphere doesn't look like real fruit, so I had to learn to embrace imperfection in the shape. It didn't necessarily look exactly like my sketch, but it taught me how to create organic shapes instead of copying a reference.

Perfume Bottle

Ideation

I chose a perfume bottle as my first model because it has a simple, elegant silhouette that felt approachable for mewhile still having enough detail to make it interesting. I liked the contrast between the smooth body of the bottle and the separate cap on top. In my sketches, I focused on the overall proportions and how the cap and neck sit on the body.

Approach

Since this was my first time using Blender, I followed a youtube tutorial to guide me. I started from the bottle shape, shaping a cylinder with the bevel tool.

Challenges + Learnings

My biggest challenge was working without a mouse. The tutorial I followed was instructing based on using a mouse, so it made it difficult to follow at first. I overcame this by learning alternative shortcut functions through google search, which ended up making me faster overall. The key skill I learned from this model was the bevel tool. Beveling the edges softened the hard corners and made the bottle look much more realistic.

Moka Coffee Machine

Ideation

I chose the Moka coffee machine because it's an interesting shape object that has a lot of character, and it's more complex than the perfume bottle. It's made up of several distinct parts: the base, the body, the spout, the lid, and the handle. In my sketches, I broke the pot down into these sections so I could plan how to build each one and how they would fit together.

Approach

I approached this render by building it in parts. I started with the main body, then added the spout and lid. The handle came last, since I wasn't sure how to build it or if there were any shortcuts instead of using the extrude tool.

Challenges + Learnings

The most challenging part was the handle. Because of this, I learned the merge surfaces function so separate pieces of geometry join into one form. I also got more practice with the bevel tool, which helped the edges of the faceted body look more realistic.
