Pond: a living ecosystem of algae, fish and herons

Project - Interactive Systems and UI

Intent

Through this Interactive Systems UI project, my learning goal was to understand the fundamentals of how a digital ecosystem functions using various rules and conditions. I was excited to create a pond ecosystem with herons, fish and algae because it was interesting to try to emulate the way nature behaves.

I was also curious to see how the amount of sunlight affected algae growth, the fish population and the heron population. I also wanted to add the emergent property of fish schooling versus not schooling, and see how that might affect the herons' ability to catch fish.

Process

Step 1Sketching the system

I created a sketch of what I imagined the ecosystem would need, mapping out physical conditions and behaviours. This was the stage where I began to understand aspects I hadn't originally considered, such as what would cause an animal's death or birth.

UML sketch goes here

Step 2Mapping the flow

Next, I mapped out the flowchart to understand each species' needs and reactions to conditions. For example, if the heron is hungry, it will chase the nearest fish. If it eats enough fish and its hunger is satisfied, it will reproduce. If it goes hungry, it will die off.

Step 3Finding the look

I found some inspiration images online of what I'd like the environment to look like, including a pixelated, game-like GIF of a pond with a muted, murky colour palette. I found this colour set both fun and appropriate for the setting.

I then decided on specifics: viewing the pond from an angle instead of a bird's-eye view, which conditions to have control buttons for, and manual tweaks along the way as I played different iterations of the p5.js sketch.

Step 4Coding the behaviour

Much of the coding and implementation was done alongside Claude Code, since my coding knowledge for a project like this is fairly limited. I tried my best to understand the functions, and how to think about defining each animal's behaviour.

Outcomes

I'm proud of how the system turned out! It was almost exactly how I imagined it in my head, and I feel I have a stronger grasp of game theory concepts.

It makes me think about games like Red Dead Redemption and GTA, which I've played and wondered how animal and NPC behaviour was controlled.
